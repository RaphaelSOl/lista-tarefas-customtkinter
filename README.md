# Lista de Tarefas - CustomTkinter

Aplicativo simples de lista de tarefas desenvolvido em Python utilizando CustomTkinter.

# Funcionalidades

- Adicionar tarefas
- Marcar tarefas como concluídas
- Excluir tarefas
- Limpar tarefas concluídas
- Contador de tarefas
- Salvamento local em arquivo JSON

# Como executar

Instale a biblioteca:

pip install customtkinter

Depois execute:

python lista_tarefas_customtkinter.py
